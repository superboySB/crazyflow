# 近地效应与双机下洗对照实验

实验对象为 `cf21B_500` 四旋翼，采用 `first_principles` 动力学，物理频率 500 Hz、数据采样 100 Hz。两组实验均在 CPU 上实际运行，离屏画面来自各自仿真状态；图中文字为中文。

## 近地效应

两个独立 world 具有相同初始状态：高度 0.05 m，水平姿态与零速度，四电机初始转速为模型重力平衡值 15,899.878 RPM。两组均施加相同恒定转速；world 0 不启用地效，world 1 在积分前显式启用 `ground_effect_fn`。

2 秒后，基线高度为 0.050000 m，启用地效组为 0.244651 m；地效附加升力的采样峰值为 0.016725 N。该实验是固定转速下的增升响应，不是闭环悬停性能试验。

地效配置：桨径 55 mm、模型系数 μ=2、最小计算高度 0.02 m、最大增益 2。

## 双机下洗

两个 world 各有上下两架无人机，初始状态相同；两组接收相同位置参考，各自根据自身状态闭环控制。world 0 不启用下洗，world 1 在积分前显式启用 `downwash_fn`。

上机高度指令为 1.2 m，下机为 0.5 m。下机先在 x=-0.5 m 保持 4 秒，再以 0.25 m/s 穿越到 x=0.5 m，末尾保持 2 秒。启用下洗后，下机向下附加外力采样峰值为 0.198520 N，y 方向附加外力矩绝对峰值为 0.00101231 N·m；与基线相比，下机高度最大差为 0.075791 m。

下洗参数：空气密度 1.225 kg/m³，桨半径 27.5 mm，对角电机距 0.1 m，推力衰减系数 0.07 s/m；远场拟合系数 BD=10.11、S=0.07668、S0=-5.817。所用源码和机型参数的 SHA-256 写入结果文件。

截图选择 10 Hz 渲染采样中两组下机高度差最大的时刻；曲线及统计使用完整 100 Hz 数据。图内的上下两架机均为真实仿真状态，不是参考轨迹替代物。

## 产物与复现

- `ground_effect_evidence.png`、`downwash_evidence.png`：中文运行画面与定量响应。
- `ground_effect_scene.png`、`downwash_scene.png`：实际双世界渲染帧。
- `ground_effect.mp4`、`downwash_comparison.mp4`：双世界实际过程。
- `ground_effect_trace.csv`、`downwash_trace.csv`：100 Hz 原始采样。
- `downwash_states.npz`：两世界、两机的完整位置和外力/外力矩采样。
- `aerodynamics_results.json`：条件、参数与统计。

在项目根目录、已安装依赖且提供 EGL 与 Noto Sans CJK 字体的 Python 3.12 环境中执行：

```bash
JAX_PLATFORMS=cpu MUJOCO_GL=egl PYTHONPATH="$PWD" \
  OMP_NUM_THREADS=1 OPENBLAS_NUM_THREADS=1 \
  XLA_FLAGS='--xla_cpu_multi_thread_eigen=false intra_op_parallelism_threads=1' \
  python peibiao_assets/aerodynamics/compare_aerodynamics.py
```

本实验验证的是显式气动插件产生的仿真响应。地效和下洗模型具有适用范围，未与本项目实机测量对照，不能作为实机一致性或迁移验收结论。
