# 公开实飞素材归属与证据范围

主文稿使用的实飞连续帧、动态图片及视频均已保存到 `real_flight/`，不再使用产品封面作为飞行证明。

公开发布者为学习系统与机器人实验室（LSY）。`real_flight/manifest.json` 记录两个原始视频的来源、发布名称、时间戳、文件 SHA-256，以及派生画面的裁切和排版规则。`real_flight/build_frames.py` 可从保存的原片重建连续帧和选定片段。

`tracking_sequence.png` 展示同一场地中无人机在八字轨迹上的连续位移；`deployment_sequence.png` 展示真实无人机离手后的恢复及空中稳定。两组材料属于原作者公开实飞，不能归属于本项目自行开展的硬件试验。

正文引用的基础模型一致性数据来自 Crazyflow 公开论文 Table 1：Crazyflie 2.1、100 Hz 姿态控制，每个条件 5 次飞行；9 秒圆轨迹的仿真—实机位置差 RMSE 为 19.0 ± 2.6 mm，3.5 秒圆轨迹为 59.6 ± 1.3 mm。该口径与实飞视频中标注的参考轨迹跟踪误差不同。

论文原始地址：`https://arxiv.org/html/2606.01478v1`。
